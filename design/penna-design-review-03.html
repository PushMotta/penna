Design review 03 · milestone D2 · 22 October 2026 · against DESIGN.md draft 3

Penna

Draft 3's new surfaces: the Defaults pill, the setup run that measures every fan and proposes curves, and fan cards that say what each fan can do. Shown in the shell's own tokens, on this desk's measured fans.

Omarchy 4.0.6 · Quickshell 0.3.2 · Qt 6.12.0 Desk Ryzen 9 5950X · Gigabyte X570 AORUS PRO (IT8688E + IT8792E) · RTX 3090 Fans 7 on the board, 2 on the GPU, 1 empty header Data simulated, shaped on the M5 hardware test

What review 01 settled

The glyph vocabulary, the popup and studio layouts, RPM before duty, and the motion constants. All of it stands. This review only adds to it, and reuses its parts.

What is new

Draft 3 made Penna for any machine. Defaults is a built-in profile, setup measures every fan and proposes curves, and fans come in seven kinds. §8.2 and §8.3 name the new UI; none of it has QML yet.

What this desk taught

M5 put the board's fans under Penna. Three findings shape this review. The BIOS's live duty can't be read on the IT8688E. A header named PUMP carries a case fan. And the BIOS stops the chipset fan when it's cool.

  1. 1

    A new install has no profile pills. Quiet, Balanced and Render would all do what Defaults does until setup fills them, so Set up fans… is the one thing to press.

  2. 2

    Every fan stays listed in Defaults, named for its header from the board database, with its RPM and who runs it. Before pairing Penna lists tachs, because it doesn't yet know which control turns which fan.

  3. 3

    The duty column is empty in Defaults. On the IT8688E, while the BIOS runs a fan, its PWM register reads the BIOS curve's start value, not the duty (M5). Penna shows only what it can measure.

  4. 4

    Defaults is the first pill, set apart by a wider gap: it hands every fan back, where the others choose curves. It counts toward the five pills of review 01.

  5. 5

    Choosing Defaults needs no confirmation. Handing back is always safe, Penna keeps showing every temperature and RPM, and the last profile is one press away.

  6. 6

    A control that turned no fan in pairing folds away under its header name. It stays with the BIOS.

Try it. On the right, press Defaults and then Balanced. The bar glyph and hero change at once; the RPMs move to the BIOS's speeds at the fans' own pace. PCH_FAN sits at 0 RPM either way: the BIOS stops it when the chipset is cool, and so does the generated curve (call 8).

C · Setup

One run, every fan, about four minutes

The setup view takes the studio over: the editor's place shows the step, the controls column shows each fan, and the sensors column becomes the guards. A simulated run of this desk plays below, faster than real time. Pairing uses the RPMs measured in M5; the rest of each fan's curve is simulated.

Guards
If a guard trips, setup stops and every fan goes back to its BIOS or driver, as it was found. The emergency rule stays in force throughout.
Setup belongs to this window: closing it stops setup and hands every fan back.
  1. 1

    Each fan's row: its name, live RPM, and what is happening to it now. Controls are named by chip and channel until pairing finds their header; then the row takes the header's name.

  2. 2

    The seven steps of §5 with their times on this desk. Done steps stay readable; a skipped load check is struck through.

  3. 3

    One panel per step. Pairing shows every tach on one scale with the one that moves in the accent. Calibration draws each fan's duty → RPM table on its own scale as it measures it.

  4. 4

    Guards, live: CPU against 85 °C, GPU against 80 °C, and the load. A tripped guard turns urgent and ends the run.

  5. 5

    One way out, where Save sits in the studio: Stop and hand back. Every fan returns at once, as it was found.

Try it. Jump to Start and run it from the beginning, or switch the load check off on the start screen. Trip a guard during any step shows what a stop looks like. In the bar, a running setup shows fan-clock, the timed-override glyph, because setup holds every fan for a while and then lets go.

G · Decisions

  
Ten calls before QML

  
All ten recommendations were approved on 22 October 2026, and recorded in DESIGN.md §11.3, with the changes they make to §4.7, §5, §8.1, §8.2 and §8.3.

  
    
    
  1. Defaults is the first pill, set apart by a wider gap. It counts toward the five pills. Choosing it needs no confirmation. Recommended: handing back is always safe, and the gap says it is a different kind of choice.
    2. 
    
  2. A profile shows as a pill once it runs at least one fan. A new install shows Defaults and Set up fans… only. Recommended: three pills that all do what Defaults does would mislead.
    3. 
    
  3. In Defaults, every fan stays listed with its RPM and who runs it, named for its header, and its duty left blank. Before pairing the rows are tachs. Recommended, from M5: the IT8688E's PWM register reads the BIOS curve's start value while the BIOS runs the fan. Needs the tick to carry tachs with their board names (protocol v2, additive).
    4. 
    
  4. Setup takes the studio over, opens on a start screen with the load check as its only option, and puts Stop and hand back where Save sits. The bar shows fan-clock while it runs. Recommended.
    5. 
    
  5. Pairing settles every fan at 60 % first, and pairs on the rise. A tach pairs with a control when its highest reading in the 6 s at 100 % is 15 % and 150 RPM above its reading just before; the drop to 40 % confirms. Recommended, from M5: this paired all seven fans by hand, where a single reading against an unsettled baseline paired one. The smallest rise from 60 % was 31 %, the PCH fan's. From the write test's 80 %, rises are smaller still. §5.2 changes to match.
    6. 
    
  6. Calibration draws each fan's table on its own scale, in small multiples, as it measures. Recommended: on one shared scale the PCH fan's 5,620 RPM flattens every other fan.
    7. 
    
  7. Roles are chips with their reason, and each fan can be named in the review. A fan on a pump header that turns out to be a case fan is held at 50 % or more until you confirm it, then measured below. Recommended, from this desk: SYS_FAN5_PUMP tops out at 1,730 RPM, under §5.3's 2,000.
    8. 
    
  8. A chipset fan may stop when the idle sample saw its firmware stop it. Calibration then measures it to a stop, and its curve rests below about 64 °C. Otherwise chipset fans never stop, as §5.3 says. Recommended, from this desk: PCH_FAN reads 0 RPM under the BIOS with the PCH at 45 °C. A never-stop curve would run it near 2,700 RPM where the BIOS keeps it silent.
    9. 
    
  9. Generated curves arrive as one draft holding all three profiles, each curve marked Generated, with its anchors drawn on the axis. Save keeps everything and switches to Balanced; Discard leaves Defaults on and keeps the measurements. Recommended.
    10. 
    
  10. Cards carry kind and tier only when they say something. The tier goes on the device heading; a card adds a kind line unless it is plain duty or NVML. Drift is a line with Recalibrate; stalled is urgent; an empty header folds away. Recommended: narrows §8.3's "each card shows its kind and tier" to what tells the user something.
    11.
